## 🏗️ Projeto em Destaque

### **Castro Materiais API**
Ecossistema de microsserviços/API REST para gestão de ERP de materiais de construção, cobrindo controle transacional de estoque, checkout de pedidos, fluxo de pagamentos e autenticação segura.

- **Arquitetura & Clean Code:** estruturação em camadas (`Controller`, `Service`, `Repository`, `DTO`), aplicando princípios SOLID e Clean Code para alta manutenibilidade.
- **Persistência Dinâmica:** isolamento de ambientes com Spring Profiles (`H2` para testes/dev e `MySQL` em produção), com estratégias de fetch otimizadas para evitar o problema do *N+1*.
- **Segurança Avançada:** autenticação stateless via `Spring Security`, com criptografia de senhas (`BCrypt`) e emissão/validação de tokens `JWT`.
- **Controle Transacional:** mecanismos de concorrência e transações ACID (`@Transactional`) para garantir a consistência do estoque durante picos de pedidos simultâneos.
- **Garantia de Qualidade:** pipeline de CI local e testes automatizados com `JUnit` e `Mockito`, cobrindo regras de negócio críticas e fluxos de integração.
